# PCDiag
Génère un rapport web complet contenant l'état du PC contenant :
- Stockage disques
- Dossiers lourds
- Etat des disques
- Liste des erreurs Event Viewer
- Synchronisation du/des OneDrive
- Services ayant de récentes erreurs
- Mise à jours disponible de WUpdate
